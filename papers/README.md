# Future papers

Working material for papers planned on top of this repository's data and analysis layer. Each subdirectory holds the paper's prospectus, pilot scripts, and figures; the pilot scripts are print-only and run against the same built artefacts as `stats/` (see `REPRODUCTION.md` for the data build). The current manuscript (the lock-in paper) lives in `paper/` and is the companion each of these cites.

| Directory | Paper | State |
|---|---|---|
| [allometry/](allometry/) | The energy allometry of settlements — ecology's allometric energy law tested on metered consumption: historic fabric scales sublinearly with settlement size, motor-era fabric does not, and the forgone economy is priced against each district's inherited compactness | Prospectus + pilot analyses (LAD settlement units; re-estimation on ONS Built-Up Areas planned) |
| [nepi_score/](nepi_score/) | The NEPI score and the online Atlas — the two-axis evaluation translated into a per-neighbourhood A–G score with frozen bands, published as an interactive national atlas | Outline (score and Atlas are built: `stats/nepi_score.py`, `stats/atlas_export.py`, `site/`, `dissemination/`) |
