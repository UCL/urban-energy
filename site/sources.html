The Atlas publishes statistical-area aggregates only: neighbourhood-level medians, counts and grades, area boundaries, and a postcode-to-area index. No addresses, property records or household-level data are re-published.

Basemap and software

The basemap is © OpenStreetMap contributors, rendered by CARTO. The map runs on MapLibre GL JS with PMTiles; tiles are built with tippecanoe. Network access is computed with cityseer.
