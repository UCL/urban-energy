# stats/archive

Retired analysis scripts, kept for provenance only. None are part of the live
two-axis build (the live layer is described in [CLAUDE.md](../../CLAUDE.md) §4);
the scripts they fed (`build_case_oa.py`, `nepi.py`, `access_penalty_model.py`,
the Atlas models) were removed in the two-axis migration and live in git history.
See [ROADMAP.md](../../ROADMAP.md).

| Script | Why archived |
| ------ | ------------ |
| `basket_index_oa.py` | Illustrative "basket index" cross-check (retired 2026-06-09). Fed the removed three-surface Access scoring, not the current analysis. |
| `basket_index_v1.py`, `build_case.py`, `diagnostic_fig1b.py`, `lsoa_figures.py`, `proof_of_concept_lsoa.py` | LSOA-era (v0) analysis, superseded by the OA-level analysis (~130 households/OA vs ~700/LSOA). |
